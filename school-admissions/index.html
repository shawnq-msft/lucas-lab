02 / 概率

没有报名分母，就没有可靠中签率。

本次找到招生计划，但没有完整可靠的各招生项、各志愿轮次有效报名人数。不能给出“人分多少、中关村多少”的真实百分比，更不能把六所学校理解为各有六分之一机会。

  1. 志愿顺序有实际作用。官方规则为：报名人数少于计划，直接录取；超过计划，随机录取；随机录取按照志愿顺序进行。若第一志愿阶段已录满，后续志愿没有剩余名额可竞争。[1]
  2. 名额多，不一定更容易。概率同时受有效申请人数、招生范围、剩余名额及志愿顺序影响。把热门校都填上，不等于获得多次独立抽签。
  3. 一派只填抽中了愿意去的。2026年一派可自愿填1—10个志愿，也可不填；公办录取不能当作可随意放弃的offer。不要为凑满数量填入不能接受的学校或借址点。二派则要求将可选学校全部按意愿排序。[1]

没有可靠数据支持把101双榆树视作“第二志愿稳保底”。本页也不提供未经核实的中考率、作业时长或升学保证。

03 / 六校比较

比较的是适配，不是名气排名。

证据标签：A 官方／校方可证明身份、计划或活动；B 教育媒体可支持具体报道；C 非官方口碑仅作访校线索。校方宣传不是独立效果评估，历史体验也不是当前承诺。

人大附中分校 人分

重点核查：教学反馈与实际就读点

有依据的特点
A2022年转为海淀区属公办。C往届家长材料提到订正、面批、教师跟进及选修资源。[4] [5]
潜在利与代价
若当前仍能落实细致反馈，适合需要明确要求的孩子。持续学业反馈是否形成压力，要看孩子适配；不能从“人分”推导出本部学籍或高中保送。
尚未核实
部分具体家长证言早至2017年、转公前，不能代表2026普通班。原址与阳春光华借址班的教师、选修共享、体育空间须分别问清。

中关村中学

重点核查：常态科技课程与清华园通勤

有依据的特点
A2026年初二科技节记录了动手实验、模型与跨学科探究，初中活动有具体证据。[6]
潜在利与代价
适合把科学兴趣列为重要考察维度的家庭。但科技节或高中项目，不能证明普通初一生每周都有稳定的科研项目时间。
尚未核实
普通班编程、工程课频次，社团准入及任课教师。三年地址按官方计划看，不采用商业校情文中互相矛盾的校区描述。

交大附中

重点核查：机器人实践与入学适应支持

有依据的特点
B教育媒体报道初中劳动课程中的采摘机器人项目，涉及传感器与动手实践。A校方介绍初一适应训练、初二积极心理训练。[7] [8]
潜在利与代价
对喜欢机器人、编程和制作的孩子，匹配证据较具体；适应支持也值得看。“幸福教育”不等于没有考试，高阶机器人项目部分面向高中。
尚未核实
新校区初中课程的持续安排、普通班能参与的项目和每周时长，以及心理支持机制当届如何落实。

北京市八一学校

重点核查：初中生能参与到什么程度

有依据的特点
A海淀教委报道过航天、卫星、无人艇等科技教育，学校确有工程实践特色。[9]
潜在利与代价
对喜欢航天和工程的孩子值得看；但部分代表性工程案例涉及高中，不能自动算作初中全员资源。
尚未核实
初中社团准入、选拔人数、实际课表和管理强度。问“普通初中生能持续做什么”，而不是只问学校有没有卫星。

101双榆树

重点核查：原址／矿大／未来科学城分别看

有依据的特点
A校方既往简介列有人文、机器人、航模等课程及社团。C2024年单班家长反馈提到活动、教师关注，也提到作业较多。[10] [11]
潜在利与代价
可从人文与科技、教学跟进两方面考察；不宜直接认作“宽松快乐校”。集团课程与培养机会不等于人人可得，更不是本部高中直升保证。
尚未核实
借址班教师、社团与分层调整机制。原址历史课程不能直接覆盖新增借址点；未来科学城的家庭时间成本应单独评估。

中关村中学知春分校

重点核查：普通班近期一手体验

有依据的特点
A教委明确集团承办、一体化管理方向，同时保持独立建制。集团教研是机制，不是与本部同等效果的证明。[12]
潜在利与代价
资源整合是潜在利好，但不能推导出本部学籍或升学保证。证据不足，不轻率贴“坑校”标签，也不直接认定“加工强”。
尚未核实
近期普通班的课堂秩序、教师稳定性、学业压力与补弱支持。缺少可比出口数据，不采用网上未经核实的普高率。
04 / 下一步

带着这六个问题访校。

  1. 资格：确切小学名称、校区和毕业年份是什么？系统实际给哪些招生项？
  2. 地址：初一到初三分别在哪里？借址持续多久？早高峰通勤能否长期承受？
  3. 教师：目标办学点的核心任课教师从哪里来？教师与课程共享如何落实？
  4. 课程：普通学生每周实际有多少编程、工程、体育和兴趣时间？社团是否选拔？
  5. 支持：作业反馈、错题订正、薄弱学科和入学适应如何处理？访谈近两届普通班家长。
  6. 取舍：若一派抽中，是否确实愿意去？若不冲一派，能否接受二派可能结果？

科技、动手兴趣导向：优先核实交大附中、中关村中学、八一的初中常态课程；重视教学反馈可重点看人分；101双榆树结合具体校址认真比较。以上是考察方向，不是六校强弱排名或最终志愿排序。

05 / 证据账本

保留原始来源，也保留不知道的部分。

没有六校同口径、可比的2026初中出口数据和独立家长样本。本页不以高中录取线、高考成绩替代初中质量；不使用来源不清的中签率和排名。链接资料有历史年份，适用范围已在正文标注。

  1. A · 2026政策海淀教委：2026年义务教育入学政策解读。用于志愿数量、录取规则和两轮区别。
  2. A · 2026计划海淀考试中心：区域三登记入学计划原图；教委发布页。用于招生区域、人数及实际办学地址。
  3. C · 2026整理北京小升初网：2026年派位入学对应学校名单汇总。含家长／平台信息，须以个人系统确认。
  4. A · 2022海淀官方：人大附中分校转公办信息。用于学校性质，不用于当前教学效果评估。
  5. C · 历史体验人分2017年家长分享转载；往届校情整理。转公前或历史材料，当前普通班／借址班未核实。
  6. A · 2026中关村中学：初二年级科技节。活动存在不等于每周常态课表。
  7. B · 2025现代教育报：交大附中采摘机器人项目。区分初中劳动课与高中高阶项目。
  8. A · 2025交大附中官网：《印象·交大附中》。校方介绍适应与心理支持，部分案例较早。
  9. A · 2023海淀教委：八一学校“上天”之后“入海”。部分学生案例为高中，不推定初中全员参与。
  10. A · 历史简介101双榆树校方简介；2021年执行校长署名文章。不证明新借址点已复制旧址课程。
  11. C · 2024单班水木101双榆树初一家长讨论。本次依据搜索索引文本，原帖有验证码；身份未经独立核实，证据强度中低。
  12. A · 历史制度海淀教委：中关村中学承办知春里中学。用于独立建制及管理机制，非当前成绩证据。
