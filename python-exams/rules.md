# 小学高年级 Python 原创模拟练习

**自编模拟题，非官方真题；题数/分值/三星预算均为本练习设定。** 面向小学3—4、5—6年级已学过基础 Python 的学生；难度混合，不等于官方年级卷。

## 上传规则已确认

- 小学分3—4、5—6年级；校内在线个人 Python 考试。
- 考试60分钟，时间结束自动提交；30分钟后可手动提交。
- 范围包括 Python基础、计算机基础、关键字、输入输出、变量、常用内置函数、数据类型、算术/逻辑/比较/位运算、顺序/循环/分支、字符串切片与方法、列表切片与方法、字典创建与方法。
- 树、动态规划、递归、文件、异常、第三方库不是这套小学练习的必修项；不把中学范围移入小学卷。
- 示例可见 `luke.move(6); luke.attack(); luke.move(-4); luke.press()`，按钮可见 move、turnLeft、turnRight、attack、press。官方完整参数、碰撞、判分语义没有确认。
- 本练习不存储或发布账号、密码、教育ID，不复制官方截图。

## 本练习自行设定

每卷8道单选、4道地图编程题，60分钟；建议选择12分钟、编程44分钟、检查4分钟。单选每题2分；编程每题最多3星、每星7分，总分100。不是官方题数、分值、难度或获奖预测。计时/提交由网页负责，Python引擎只评测一道地图题。

地图与 inputs 的全部输入可见；`scenario` 是公开地图/目标元数据，不是隐藏测试。JSON的true/false/null在Python中对应True/False/None。每次运行深复制输入和地图，修改列表不会污染下次运行。

### 自编模拟器动作语义（不代表官方引擎）

坐标从左上角(0,0)起，x向右、y向下；朝向0东、1南、2西、3北。

- `move(n)`：n须为整数（不能为bool），沿当前朝向走n格；负数是保持朝向后退，不是转身。逐格检查越界、墙与活跃敌人；不能穿过它们。0格也计一次动作。
- `turnLeft()`/`turnRight()`：左/右转90度，各计一次动作。
- `attack()`：正前方相邻格必须有活跃敌人，消灭一个；空击失败。
- `press()`：脚下必须有尚未按下且required=true的开关；误按、禁按、重复按都失败。
- 全局五个动作由hero执行；`hero.move(...)`和`luke.move(...)`等对象方法只控制同名角色；不在地图中的角色不能调用。角色之间允许共享格子；只有墙、地图边界和活跃敌人阻挡。
- 要求所有required开关按下、非required开关不按、全部敌人消灭、所有指定角色到终点。朝向除非题目明确说明，不作为终点条件。
- 没有goto、探测/寻路、地图读取等额外游戏API。学生仅可用公开inputs及上述动作，print/input是普通Python辅助（input仅从公开stdin队列读）。

### 本练习近似判分

- 附件样题：未过关不得星；过关后从3星起，未用指定知识、代码过长分别扣1星。
- 模拟器以语法结构近似识别指定知识，不证明该结构实质发挥作用；用行动调用次数预算近似衡量简洁性，不是官方最简代码判定。
- 若题目有maxStatements，额外限制AST中的语句数；本套未使用此限制。
- 空代码、语法错、越界、误按/空击、未知API、超限或目标未达成都0星。已执行的动作保留在回放中；最后一帧给出原因。

## 安全与执行限制

仅使用CPython/Pyodide共有标准库。禁import、双下划线、函数/类定义、异常处理、文件/网络/系统访问、eval/exec、反射与动态API选择。引擎白名单语法/调用并限制数值、字符串、容器、代码长度、动作数、移动格数、运行行数、表达式和回放帧数，防止常见无限循环与过量运算。它是教学用受限解释执行，不应当作隔离任意恶意代码的安全边界；网页仍应在独立Worker中运行并设置终止超时。

答案只在单独的solutions.json中；exams.json和engine.py不包含参考答案。客户端答案文件不是安全保密机制，部署时应让学生在首次提交之后主动查看。独立初次作答不应使用AI/补全；之后可用提示订正。仅据练习暴露知识缺口，不估计官方奖项。
